資訊組安裝檢查表

鱻魚特色學園（Minecraft 教育版）電腦教室準備・建議上課前兩週完成，交給授課老師前逐項打勾。

一、整間教室一次設定

✓項目怎麼做／怎麼確認備註
學校授權確認學校的 Microsoft 365 教育版授權包含 Minecraft 教育版
學生帳號啟用上課班級的教育雲帳號都已到 o365.k12cc.tw 啟用 Microsoft 365（部分縣市用縣市單一登入）
帳號清單全班帳號、密碼清單交給授課老師；學校 Gmail 不能用（會出現 AADSTS500200）
安裝方式選一種：Microsoft Store、官方下載頁 安裝檔、winget install "Minecraft Education" --scope machine、群組原則或 Intune 派送
Store 更新用 Microsoft Store 安裝時，先讓其他 App 的更新跑完，否則會擋住安裝
還原卡上課期間暫停還原，或把世界資料夾設為不還原（路徑見第三節）；課程結束再恢復
世界檔從 課程網站 下載學生版世界檔（約 13 MB），放到每台桌面或共用資料夾
耳機每台一副，插上確認有聲音
教師機老師電腦同樣安裝、可登入、已匯入世界檔，接上投影

⚠️ 清理時不要用「解除安裝」：官方說明指出，解除安裝會刪掉這台電腦所有使用者建的世界。要清世界，請在遊戲的世界清單按「編輯 → 刪除世界」。

三、查版本與資料夾的方法

查版本（Microsoft Store 安裝的版本）

在每台電腦開 PowerShell 貼上這行，會顯示版本號：

Get-AppxPackage *MinecraftEducation* | Select-Object Name, Version

沒有任何輸出，代表這台沒裝 Store 版本（可能是用安裝檔裝的，或根本沒裝），請直接開遊戲確認。

世界資料夾（還原卡要排除的位置，Store 版本）

%LOCALAPPDATA%\Packages\Microsoft.MinecraftEducationEdition_8wekyb3d8bbwe\LocalState\games\com.mojang\minecraftWorlds

這個資料夾在每個 Windows 使用者自己的設定檔底下；電腦教室若每台共用同一個 Windows 帳號，就排除那個帳號底下的這個資料夾。
