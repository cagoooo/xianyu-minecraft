電腦教室備課流程

在學校電腦教室（Windows）開這門課，照這份從頭做一次就能上課；第一次帶的老師也適用。

分工一覽

什麼時候誰來做要做好什麼
兩週前資訊組授權與帳號、每台電腦安裝並更新教育版、還原卡、耳機
一週前授課老師自己玩一遍、在教室的電腦用學生帳號完整測一次、印學習單與操作小卡
上課前一天授課老師（或資訊組）世界檔放到每台電腦、開機讓遊戲更新完
每節課授課老師開場 10 分鐘帶登入與進世界、下課前 3 分鐘帶存檔與記通關碼
課程結束授課老師印通關證書、整理電腦裡的世界

一兩週前：資訊組準備 資訊組

🧾 給資訊組的可列印版：資訊組安裝檢查表（整間教室設定＋逐台打勾表＋驗收簽名）。

1. 授權與帳號

  • 確認學校有 Minecraft 教育版授權（Microsoft 365 教育版）
  • 學生要用組織帳號登入：教育部教育雲帳號要先到 o365.k12cc.tw 啟用 Microsoft 365 才能用（部分縣市可用縣市單一登入，請依縣市規定）
  • 學校 Gmail 這類帳號在微軟算「個人帳號」，會被拒絕（畫面出現 AADSTS500200）
  • 整理全班帳號清單，上課時發給學生（密碼不要寫在黑板上）

2. 每台電腦安裝教育版

  • 從 官方下載頁 或 Microsoft Store 安裝「Minecraft Education」
  • 多台一次裝：可用 winget install "Minecraft Education" --scope machine（替這台電腦所有使用者安裝），或用群組原則、Intune 派送（官方有說明文件）
  • 版本要夠新：本課程在 1.26.3300 版測試，版本太舊時阿凱老師和任務可能不會動；開遊戲時有更新就先更新
  • 用 Microsoft Store 安裝時，其他 App 有待更新會擋住安裝，先把 Store 的更新跑完
⚠️ 不要用「解除安裝」來清理：官方說明指出，解除安裝會把這台電腦所有使用者建的世界一起刪掉，學生的進度也會不見。

3. 還原卡（還原系統）

  • 電腦教室若裝了還原卡，重開機後，匯入的世界和闖關進度都會消失
  • 上課這 3 節期間，請暫停還原，或把教育版的世界資料夾設為不還原
  • 真的不能暫停時：每節課都要重新匯入；第 2 節要先過第 1 節的 4 站才拿得到通行證，學生得重闖 4 站

4. 耳機與輸入法

  • 每台準備耳機：全班同時播阿凱老師的語音和背景音樂，用喇叭會很吵
  • 電腦預設輸入法若是中文，學生進遊戲前先按 Shift 切成「英」，避免中文輸入法攔走按鍵

二一週前：授課老師試教 授課老師

  1. 自己先玩一遍：從 課程網站 下載學生版世界檔（約 13 MB），走完第 1 節內容（4 個問答站），知道每一站在哪裡。
  2. 到電腦教室挑一台，用「學生帳號」完整測一次，逐項打勾：
    • 學生帳號登入成功
    • 雙擊世界檔能匯入，世界清單出現「鱻魚特色學園（學生版）」
    • 進世界看到歡迎標題，戴耳機聽得到阿凱老師的聲音和背景音樂
    • 對 NPC 按右鍵會跳出題目，答對答錯都有聲音
    • 畫面不卡（卡的話：設定 → 視訊 → 顯示距離調小）
    • 儲存並離開後重新進世界，進度還在
    • （有還原卡）重開機一次，世界和進度還在
  3. 印資料：學習單 依節次每人一份；本頁最後的 學生操作小卡 每台電腦一張（可護貝重複用）。
  4. 排座位：每位學生固定坐同一台電腦（建議座號對電腦號）。進度存在那台電腦裡，換電腦要從頭開始。

三上課前一天：放好世界檔 授課老師／資訊組

  1. 把學生版世界檔複製到每台電腦的桌面，或放在全班看得到的共用資料夾（網路芳鄰、廣播系統派送都可以）。
  2. 每台開機、打開一次教育版，讓更新跑完，避免上課時全班一起等更新。
  3. 老師電腦也開好一份世界，用來示範；可輸入 /scriptevent akai:remote 拿老師遙控器（集合、廣播只對同一個世界裡的人有效）。
💡 同一台電腦有好幾個班級要用時：進度跟著「那一份世界」走，不會分班。每一班各自匯入一份，匯入後在「編輯 → 世界名稱」改成「鱻魚-班級-座號」（例如「鱻魚-401-05」），下次就找得到自己那份。（改名請在一週前的測試一起試過。）

四第 1 節開場 10 分鐘 授課老師

時間學生做什麼老師注意
0–3 分戴耳機、輸入法切「英」、打開 Minecraft Education投影示範畫面，發帳號清單
3–6 分用自己的帳號登入第一次登入比較慢；登不進去的先記下來，不要整班停下來等
6–8 分雙擊桌面的世界檔匯入（已匯入就到「遊玩」選世界）匯入完成會跳出提示；多班共用電腦時帶學生改世界名稱
8–10 分進世界，聽阿凱老師開場，看畫面上方的「目前任務」用操作小卡複習：WASD 走路、滑鼠右鍵說話

接下來照 教案第 1 節 進行。第 2、3 節開場只要「登入 → 遊玩 → 選同一份世界」，約 3 分鐘。

五每節下課前 3 分鐘 授課老師

  1. 請學生找阿凱老師按「我的進度」，把 7 碼通關碼寫在學習單上（印證書要用）。
  2. 按 Esc →「儲存並離開」，回到主畫面再關遊戲。直接關機，進度可能沒存到。
  3. 有還原卡又沒辦法暫停時，通關碼就是這節的成績紀錄，一定要記下來。

六課程結束後 授課老師

  • 到 印通關證書 輸入學生的通關碼，印出證書
  • 收回學習單，依 評量 打分
  • 整理電腦：在遊戲的世界清單，對不要的世界按「編輯 → 刪除世界」（不要用解除安裝遊戲的方式清）
  • 還原卡恢復原本設定

七、電腦教室常見狀況

狀況處理
登入出現 AADSTS500200用了個人帳號（例如學校 Gmail），改用教育雲啟用的 Microsoft 365 帳號
登入次數不夠、要求付費帳號沒有正式授權，請資訊組確認學校授權
按鍵沒反應、角色不會走中文輸入法攔走按鍵，按 Shift 切「英」
阿凱老師不說話、任務不出現沒戴耳機或音量太小（設定 → 音訊）；或遊戲版本太舊，請資訊組更新
上一節的進度不見了還原卡把電腦還原了、上次沒有「儲存並離開」，或選到別班那一份世界
世界清單有好幾個同名的世界重複匯入了。選最近玩過的那份，之後照第三步改名區分
畫面卡頓設定 → 視訊 → 顯示距離調小，關掉其他開著的程式

遊戲內的問題（卡關、走不到景點、通關碼）請看 教案的疑難排解。

學生操作小卡

開始玩

  1. 戴上耳機，按 Shift 把輸入法切成「英」
  2. 打開「Minecraft Education」，用老師發的帳號登入
  3. 第一次：雙擊桌面的世界檔；之後：按「遊玩」→ 選自己那份世界
  4. 看畫面上方的「目前任務」，跟阿凱老師說話開始闖關

按鍵

WASD 前、左、後、右走
移動滑鼠　轉頭看方向
空白鍵 跳
滑鼠右鍵　跟 NPC 說話、按按鈕
1～9 換手上拿的東西
Esc 暫停、儲存並離開

下課前

  1. 跟阿凱老師按「我的進度」，把通關碼寫在學習單上：＿＿＿－＿＿＿＿
  2. 按 Esc →「儲存並離開」，再關遊戲
